  <action>
    Implement the two new `submissionsForGrading` methods in `Submission.java`.

    1. `public static SubmissionGradingState submissionsForGrading(NSArray<AssignmentOffering> offerings, NSDictionary<AssignmentOffering, NSArray<User>> users)`
       - Create a new `SubmissionGradingState(offerings, users)`.
       - Call `submissionsForGrading(state)`.
       - Return the state.

    2. `public static SubmissionGradingState submissionsForGrading(SubmissionGradingState state)`
       - **Phase 2 Implementation Steps**:
         - Determine the `EOEditingContext` from the first offering in `state.offerings()`. If none, return state.
         - Build `EOQualifier` for the fetch:
           - Use `assignmentOffering.in(state.offerings())`.
           - If `state.users()` is not null, add `user.in((NSArray<User>)state.users().allValues().valueForKey("@flatten"))`.
         - Create `WCFetchSpecification` for `ENTITY_NAME`.
         - Set prefetching for "result" and "user" relationships.
         - Fetch submissions.
         - **Merging Loop**: For each fetched `Submission`:
           - Determine its `AssignmentOffering` and `User`.
           - Get the corresponding `Map<User, StudentSubmissionInfo>` for the offering from `state`.
           - Find the `StudentSubmissionInfo` for the user.
           - If not found: Create a new `StudentSubmissionInfo` for this user/offering with an empty `NSMutableArray<Submission>`, and add it to the user map.
           - Append the new `Submission` to the `StudentSubmissionInfo.allSubmissions` list (cast to `NSMutableArray` if needed).
           - Set `StudentSubmissionInfo.isDirty = true`.
         - **Re-evaluation Loop**: Iterate through all `StudentSubmissionInfo` objects in the `state`:
           - If `isDirty == true`:
             - Sort the `allSubmissions` list by `submitTime`.
             - Reset `gradedSubmission = null`.
             - Iterate through `allSubmissions` (sorted) and update `gradedSubmission` using the existing `isBetterGradingChoiceThan` logic.
             - Reset `isDirty = false`.
         - Update `state.lastFetchTimestamp = new NSTimestamp();`.
         - Return `state`.

    **Implementation Details**:
    - Add `import java.util.HashMap;` to imports if not present.
    - Use `java.util.HashMap` for the inner maps of `SubmissionGradingState`.
    - Use existing constants from `_Submission` (ENTITY_NAME, assignmentOffering, user, submitTime, RESULT_KEY, USER_KEY).
    - Use `ERXQ.and()` for joining qualifiers.
    - Reference the existing `NO_SUBMISSIONS` constant defined in `Submission.java`.
