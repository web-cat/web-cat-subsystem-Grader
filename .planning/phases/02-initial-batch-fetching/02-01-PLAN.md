  <action>
    Implement the two new `submissionsForGrading` methods in `Submission.java` (typically after the `SubmissionGradingState` class).

    1. `public static SubmissionGradingState submissionsForGrading(NSArray<AssignmentOffering> offerings, NSDictionary<AssignmentOffering, NSArray<User>> users)`
       - Create a new `SubmissionGradingState(offerings, users)`.
       - Call `submissionsForGrading(state)`.
       - Return the state.

    2. `public static SubmissionGradingState submissionsForGrading(SubmissionGradingState state)`
       - **Core Logic**:
         - Determine the `EOEditingContext` from the first offering in `state.offerings()`. If empty, return state.
         - Build `EOQualifier` for the fetch:
           - Use `assignmentOffering.in(state.offerings())`.
           - If `state.users()` is not null, add `user.in((NSArray<User>)state.users().allValues().valueForKey("@flatten"))`.
         - Create `WCFetchSpecification` for `ENTITY_NAME`.
         - Set prefetching for "result" and "user" relationships.
         - Set sort order to `submitTime.descs()`.
         - Fetch submissions.
         - Group submissions by `AssignmentOffering` and `User`.
         - For each user in each offering:
           - Iterate through their submissions (already sorted by time) to identify the `gradedSubmission` using `isBetterGradingChoiceThan(bestSoFar)`.
           - Create a `StudentSubmissionInfo` object.
           - Add to the internal map of the `state`.
         - Ensure that all requested users (if specified) have a `StudentSubmissionInfo` entry even if they have no submissions (use `NO_SUBMISSIONS` constant).
         - Update `state.lastFetchTimestamp = new NSTimestamp();`.
         - Return `state`.

    **Implementation Details**:
    - Add `import java.util.HashMap;` to imports if not present.
    - Use `java.util.HashMap` for the inner maps of `SubmissionGradingState`.
    - Use existing constants from `_Submission` (ENTITY_NAME, assignmentOffering, user, submitTime, RESULT_KEY, USER_KEY).
    - Use `ERXQ.and()` for joining qualifiers.
    - Reference the existing `NO_SUBMISSIONS` constant defined in `Submission.java`.
